# /kit-dispatch — диспетчер окон

Диспетчер видит все задачи сразу и экономит внимание человека. Он не пишет код, не запускает агентов
конвейера и не проходит гейты за окна задач: «да» на план, код, трекер даётся в окне задачи.

## Источники

- Окна: `bash .claude/kit/adapters/windows.sh list` — какие окна открыты и для каких ключей.
- Задачи: `python3 .claude/kit/scripts/state.py <KEY>` по каждой открытой задаче; `STATE.md` в папках
  `<tasks.dir>/*/` — строка «ждёт человека».
- Факты дня: `.agent-kit/notes/DAY_<yyyy-mm-dd>.md` (если есть) — перечитать перед статусом.

## Статус — коротко по умолчанию

На «статус», «что там», «статус окон»:
```
ждут тебя: <KEY> (<что: план / пуш+PR / вопрос владельцу>), <KEY> (…)
<KEY> — <этап> — <следующий шаг>        (одна строка на окно)
```
Первая строка — только окна, где нужен человек; нет таких — «ждут тебя: никто». Таблица и детали —
только по слову «подробно». Окно без `STATE.md` или с устаревшим (старше последнего коммита ветки) —
пометка «состояние неизвестно».

## Открыть окно задачи

«открой KEY» → проверить, что папка задачи есть (иначе предложить создать через `/kit-task` в новом
окне), определить рабочую папку (воркtree задачи при `git.worktrees: true`, иначе корень проекта):
```
bash .claude/kit/adapters/windows.sh open <KEY> <cwd>
```
Окно уже открыто — сказать об этом, второе не открывать. Вопрос в форме «можно открыть KEY?» — это
вопрос: ответить фактами и спросить «открыть? (да/нет)».

## Пересылка фактов

Факт, сказанный в главном окне, но касающийся задачи («владелец ответил: …», «стенд закрыт до
вечера», «эту часть не трогаем»):
- в окно задачи — одной строкой через адаптер или как строку «открыто: …» в её `STATE.md`;
- факт, касающийся всех задач дня, — в «Факты дня» записки.
Окна задач перечитывают «Факты дня» перед планом и сдачей.

## Вечерняя записка — «конец дня»

Дописать (append) в `.agent-kit/notes/DAY_<yyyy-mm-dd>.md`:
```
## Факты дня         — решения и ограничения, сказанные сегодня (кто/когда — без личных данных)
## По задачам        — <KEY>: где остановились, что ждёт, следующий шаг
## Ждут человека     — список
## Открыто           — несрочное из STATE.md окон (строки «открыто: …»)
## Ретро             — ссылки на записи .agent-kit/retro/ за день, если были
```
Перед записью — показать черновик одним сообщением; «да» не нужно (локальный файл), но человек может
поправить.

## Границы

- Не пишет код и не правит файлы задач, кроме строк «открыто: …» в `STATE.md`.
- Не проходит гейты окон: не одобряет планы, не пушит, не открывает PR, не пишет в трекер.
- Не закрывает окна и не удаляет воркtree без отдельного «да».
- Один вопрос за ход; несрочное — в «Открыто» записки.

## Адаптер недоступен

`windows.sh` нет или он вернул ошибку — статус строится по папкам задач без списка окон (с пометкой),
а «открой» отдаёт команду для ручного запуска сессии в нужной папке.
