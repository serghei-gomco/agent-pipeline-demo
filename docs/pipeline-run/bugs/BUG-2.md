# BUG-2 — активный режим переключателя «Все / Просроченные» на вид не отличим

- Кейс: QC-84 (AC-15, R-11; дыра плана D-6)
- Sha HEAD: e722fb1bfaed515207586dd2fad1f608f4de1094, ветка `feat/T-20261112-1-due-dates`
- Браузер: Google Chrome 157.0.8103.51 (headless, Playwright 1.66 `channel: 'chrome'`)

## Шаги воспроизведения

1. `bash scripts/node.sh npm run dev`, открыть `http://localhost:5173`.
2. Посмотреть на кнопки «Все» и «Просроченные» (по умолчанию активна «Все»).
3. Нажать «Просроченные», увести фокус (клик по заголовку), снова посмотреть.

## Ожидаемо (QA_PLAN, QC-84)

Активный режим отличим на вид. (План заранее предупреждал, что правила для `aria-pressed` в CSS нет и режимы, вероятно,
будут неотличимы, — «записать как находку».)

## Фактически

Вычисленные стили обеих кнопок одинаковы в обоих режимах: `background rgb(239, 239, 239)`, `color rgb(0, 0, 0)`,
`border 2px outset`, `font-weight 400`, без подчёркивания и тени. Меняется только атрибут `aria-pressed`, который виден
лишь скринридеру. Зрячий пользователь не может понять, какой режим включён, кроме как по содержимому списка
(а при пустом результате видна только надпись «Нет просроченных задач»).

## Доказательства

- `evidence/QC-84.txt` — стили обеих кнопок в режиме «Все» и в режиме «Просроченные».
- `evidence/QC-84-all-active.png`, `evidence/QC-84-overdue-active.png` — снимки блока переключателя, визуально идентичны.
