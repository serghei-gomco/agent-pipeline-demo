# T-20261112-1 — due-dates-overdue

Источник: демо-задача (ТЗ написано заказчиком-ролью «продакт»), 12.11.2026

## ТЗ (дословно)

Нужны сроки у задач.

1. У задачи появляется необязательный срок — дата без времени (`dueDate`, формат `YYYY-MM-DD`).
   Срок можно указать при создании, поменять и убрать у существующей задачи.
2. Сервер не принимает кривые даты: не тот формат и несуществующие дни (например 30 февраля) — ошибка 400
   с понятным текстом, как у остальных полей.
3. В списке рядом с названием показываем срок. Просроченные задачи выделяем красным.
4. Над списком — переключатель «Все / Просроченные». В режиме «Просроченные» показываем только просроченные;
   если таких нет — текст «Нет просроченных задач».
5. Просрочена — задача, у которой срок раньше сегодняшнего дня. Задача со сроком «сегодня» ещё не просрочена.
   «Сегодня» — по часам пользователя, в его часовом поясе.

  срок давно прошёл, и в режиме «Просроченные» их быть не должно. Счётчик в заголовке («N open») не трогаем.
