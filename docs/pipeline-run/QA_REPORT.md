`http://localhost:5173` в Chrome. Входа и ролей нет; список пустой после каждого перезапуска.

1. Введите название «Оплатить счёт», в поле «Due date» выберите завтрашнюю дату, нажмите «Add».

2. Создайте задачу «Старая» со вчерашней датой и задачу «Сегодня» с сегодняшней.
   Ожидаемо: «Старая» — название и дата красные; «Сегодня» и «Оплатить счёт» — обычного цвета.
3. Нажмите «Просроченные». Ожидаемо: видна только «Старая»; число в заголовке «Tasks (N open)» не изменилось.
   Отметьте «Старая» выполненной — она пропадает из списка, появляется «Нет просроченных задач». Нажмите «Все» —
   видны все задачи, «Старая» зачёркнута и не красная.
4. У задачи «Сегодня» поменяйте дату в поле строки на прошлую и кликните в пустое место; обновите страницу (F5).
   Ожидаемо: новая дата сохранилась, задача стала красной. Затем очистите дату в строке, кликните в пустое
   место, F5 — срока у задачи нет.
5. Выберите дату в календаре строки и сразу нажмите F5, не кликая мимо. Ожидаемо по замыслу: изменение не
   сохраняется (сохранение — только при уходе из поля). Запишите, удобно ли так.
6. Не закрывая страницу, остановите приложение (Ctrl+C в окне, где оно запущено) и поменяйте дату в строке,
   кликните мимо. Ожидаемо: появился красный текст ошибки, рядом с названием — прежняя дата. Запустите приложение
   снова и обновите страницу (список будет пустым — это нормально для демо).
7. Посмотрите, видно ли на глаз, какой режим сейчас выбран — «Все» или «Просроченные».

Баг: просроченной считается задача со сроком «сегодня»; выполненная задача красная или видна в «Просроченных»;
после F5 дата другая, чем вы сохранили; счётчик «N open» меняется от переключения режимов; после ошибки
сохранения форма создания стирает введённое; страница пустая или «зависла» после ошибки.
